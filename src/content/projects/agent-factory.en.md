Agent Factory takes an issue whose specification the operator has validated and carries it to a pull request. One agent writes acceptance checks that prove each criterion from the outside. The factory runs them on the base, where they must fail by assertion, then freezes them by hash. Another agent implements the change, and a gate in its Stop hook holds the session until the frozen checks, lint and tests pass. The factory runs the gate again in its own sandbox, an agent in a fresh context reviews the change against the spec and the checks, and the pull request opens with the evidence before and after. The merge happens on the operator's order. A failure gets two corrections in the same session, then one fresh restart, and after that the issue waits for a person, with the reason. Everything the factory does is an event appended to one SQLite log. The cockpit, the status command and the decisions of the daemons are projections of that log. Agents and check commands run in the operating system's sandbox, away from credentials and from other projects. The factory reads the subscription's usage and pauses before a limit. A demonstration plays a working week of two fictional teams with a fake Claude, with no account and no network. Agent Factory is the final version of an idea started in September 2025 with Claude Autopilot, which ran a project's tasks one after the other through Claude Code with quality gates and a watchdog, and continued in 2026 with Claude Plan Execute.
