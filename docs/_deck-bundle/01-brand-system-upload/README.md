# Brand-system upload folder

Optional drop-zone for concrete brand assets you want Claude Design to weigh — a specific licensed font file, a logo, or an inspiration screenshot. Attach via the setup form's "Add fonts, logos and assets" option (see ../README.md Step 3). **Usually left empty:** the typographic direction and full brand direction are already spelled out concretely in `../../design-system-setup.md`, so no upload is needed for Claude to act on them.
